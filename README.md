# Enzo Portfolio

Fundação estática do portfólio profissional de Enzo, construída com Astro, TypeScript, Tailwind CSS, Decap CMS e Cloudflare Pages.

## POC atual

- Rota pública que lista projetos publicados em Markdown.
- Rota `/about` mínima.
- Rota `/admin` com Decap CMS e coleção de projetos.
- Pages Functions para o fluxo OAuth GitHub do Decap CMS.
- Conteúdo modelado para animação 2D, storyboards, sketchbooks, ilustrações e projetos autorais.

Consulte [configuração local](./docs/setup.md), [OAuth](./docs/oauth.md) e [publicação](./docs/deploy.md).
