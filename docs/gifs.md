# GIFs animados

No campo **Galeria e videos**, escolha **GIF animado** e envie um arquivo `.gif`. O mesmo tipo de arquivo pode ser usado como capa de projeto e em secoes de imagem da pagina inicial.

GIFs preservam a proporcao original, reproduzem automaticamente em loop e podem ser ampliados no lightbox. O preview do Decap usa `getAsset()` para mostrar uploads temporarios antes do commit.

O upload mantem o arquivo original e nao faz conversao automatica. Use GIFs otimizados e com dimensoes adequadas para a web. Para animacoes grandes, avalie uma versao leve ou YouTube/Vimeo; o suporte nativo a GIF continua disponivel.
