# Edição do portfólio

Abra `/admin` e faça login com sua conta GitHub autorizada.

## Projetos

Use **Todos os projetos** para criar ou editar uma obra. As áreas de Animações, Storyboards, Sketchbooks e Ilustrações mostram os mesmos arquivos filtrados por categoria. Marque **Publicado** para exibir a obra, **Em destaque** para a seleção inicial e use **Ordem de exibição** (menor aparece primeiro).

Em **Galeria e vídeos**, arraste os itens para mudar a ordem. Para imagens, envie um arquivo; para vídeos, use uma URL pública do YouTube ou Vimeo. A capa aparece nos cartões da página inicial.

## Perfil e aparência

Em **Página Sobre**, atualize nome, textos, foto, formação, trajetória, especialidades, links e currículo. Os controles de seções escondem áreas vazias sem apagar seu conteúdo.

Em **Aparência do site**, os presets controlam fundo, tipografia, colunas, capas, espaçamento, destaque e rodapé. Eles são opções seguras: não exigem código nem alteram o conteúdo das obras.

Cada salvamento cria um commit no repositório. O Cloudflare Pages reconstrói o site automaticamente após o commit.
